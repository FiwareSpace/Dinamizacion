### Descripción de las diferentes carpetas:

- Diferentes versiones: versiones desechables de codigos anteriores

- Arduino_V4_conexionesWifManage.ino: codigo en C++ para la placa ESP32

- Arduino_V4_conexionesWifManage.zip: carpeta comprimida donde se encuentra el codigo en C++ para la placa ESP32 y todas las librerias usadas en el codigo (se recomienda descargar este archivo .zip para optimizar el rendimiento del codigo).
